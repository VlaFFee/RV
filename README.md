# RealView (Forge 1.20.1)

Реалистичный вид от первого лица: покачивание головы, наклоны при стрейфе и поворотах, удар при приземлении,
толчок при прыжке, дыхание, пульс при низком здоровье, инерция и качание рук, поза рук при беге, FOV от скорости.

## Тело от первого лица (1.1)
Если смотреть вниз, видно своё тело: торс, ноги, броню. Рисуется настоящий рендерер игрока после сущностей мира,
без головы, рук и предметов в руках (они уже есть в виде рук), тело чуть отодвинуто назад. Вкладка «Тело»:
включение, сдвиг, скрытие предметов. Не показывается при плавании, ползании, полёте на элитрах, сне, в седле,
в клипах FP Studio и (по настройке) во время действий ParCool. При ошибке рендера функция сама отключается до перезапуска.
Не гарантируется с шейдерами (Iris/Oculus) и модами, рисующими предметы на голове (Curios).

## Совместимость с ParCool (1.1)
Через reflection (`Parkourability.get(player)` -> действия -> `isDoing()`) и независимо от этого по позе игрока.
Во время действий ParCool (кувырок, перелёз, бег по стене, уклон, зависание...) камера и руки плавно успокаиваются
до заданной доли, удар при приземлении откладывается на ~0.12 с и смягчается, если ParCool ответил кувырком;
ползание и скольжение лишь ослабляют покачивание. Вкладка «ParCool» в настройках.

## Настройки
- Моды -> RealView -> **Настройки** (Config)
- клавиша `;` (меняется в управлении), команда `/realview`
- файл `config/realview-client.toml`
- вкладки: Общее / Ходьба / Реакции / Руки / Тело / ParCool / FP Studio; пресеты «Лёгкий», «Реалистичный», «Кино»

## Совместимость с FP Studio
- Мод не двигает игрока и не отменяет рендер рук, только добавляет углы/FOV и поворот на общий PoseStack.
  Поэтому не конфликтует с камерой FP Studio, которая сдвигает игрока на кадр.
- Пока идёт клип или открыта студия, эффекты **плавно гаснут** и так же плавно возвращаются (время: `fpstudioFadeTime`).
  Режимы: `PAUSE_ALL` (по умолчанию), `KEEP_CAMERA`, `KEEP_ALL`.
- Связь через reflection (`com.fpstudio.client.Playback.active()`): без FP Studio мод работает сам.
- Ванильное покачивание вида отключается только на время кадра (настройка видео не меняется).

## Сборка
Как у FP Studio: JDK 17 + `gradle build` (есть `.github/workflows/build.yml`). Готовый jar: `build/libs/`.
